## 已确认缺口

1. **无效邀请码导致注册反复失败。** 无效或已停用邀请人的邀请码被缓存到 `tgg_pending_invite`，接口每次返回“邀请码无效”；失败不清缓存，普通重新进入也不清缓存。登录页面没有更换或清除邀请码的操作。可以通过新的有效邀请卡片替换，但应用自身缺少明确恢复入口。相关代码：`wechat-miniprogram/app.js`、`utils/auth.js`、`pages/login/index.js`、`dev/backend/src/services/auth-service.js`。
2. **后台邀请审计提成统计不准确。** 提成流水 `bizNo` 是任务提交单 ID；`listInviteAudits()` 却判断该字符串是否包含被邀请人用户 ID。复现结果为邀请人已收到 10 积分、用户邀请列表贡献为 10，后台审计贡献为 0。应通过任务提交单的 `userId` 关联被邀请人，和用户端统计保持一致。相关代码：`dev/backend/src/services/admin-service.js`、`growth-service.js`。
3. **复制邀请码入口缺少手动填写配套。** 邀请页提供复制按钮，但当前登录页没有邀请码输入框；单纯复制发送给好友无法在页面内完成绑定。有效路径仍是携带邀请码的小程序分享卡片。
4. **网页邀请链接仍是示例地址。** `getInviteInfo()` 返回 `https://tgg.example/register?invite=...`。这条地址不是已验收的正式注册入口，小程序分享卡片使用独立路径，不依赖它。

注册奖励与任务提成是两类流水，邀请页“累计提成”和列表“贡献”只统计任务提成，因此刚完成注册时列表贡献为 0 不代表 3 积分注册奖励未发放。

## 尚未覆盖的外部验收

需真实微信账号在两个设备上完成“发送分享卡片—打开—微信手机号授权—注册—邀请人刷新记录”的验收，才能确认线上隐私声明、手机号权限、分享投递和真实网络环境均可用。此次自动化结果不等同于已完成微信真机验收。
