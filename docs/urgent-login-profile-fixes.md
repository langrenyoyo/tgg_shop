# 《小鹿加急修改.docx》修复记录

## 1. 微信头像、昵称和选图

文档要求登录后能使用微信头像和昵称，并修复点击头像无反应、不能选图的问题。

实现：点击头像打开相册/拍照，单独提供微信原生 `chooseAvatar` 入口；昵称使用 `type="nickname"`，可选择微信昵称或填写。选图取消保留原头像，权限失败有提示，上传失败可重试。微信现行能力不支持登录后静默读取真实头像和昵称，因此由用户主动授权选择，不伪造自动获取。

## 2. 登录时手机号授权

文档截图为微信原生手机号授权弹窗，使用 `open-type="getPhoneNumber"` 实现，不绘制仿制弹窗。勾选说明后点击登录获取手机号授权 code，连同 `wx.login` code 发送到后端；后端通过微信接口验证手机号后才注册或发放登录会话。拒绝授权不创建账号、不发放邀请奖励。

已有未绑定手机号的登录账号可补绑，不重新创建账号。手机号属于其他账号或与已有门店资料不一致时提示人工核对，不合并积分和会员。已验证的号码复用于门店会员建档，避免重复授权。

## 上线与验收

需同步更新后端及小程序，并确保微信后台已开通手机号能力、完善隐私保护指引。头像/手机号授权弹窗和微信昵称填充须在真机验收；自动化测试覆盖拒绝授权、并发注册、手机号冲突、原账号补绑、选图取消/失败及跨账号异步结果隔离。
