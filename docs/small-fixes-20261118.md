# 小问题 20261118：分析与修复

依据《小问题20261118.docx》及补充要求“第二点搜索完后分类回到全部分类中”。

| 问题 | 原因 | 修复 |
| --- | --- | --- |
| 左侧缺少“全部”分类 | 分类菜单仅使用接口返回的商品分类与业务专区 | 左侧首项固定显示“全部”，默认选中，点击时清空搜索关键词、从第一页显示全部在售商品 |
| 选中具体分类后无法搜索其他分类商品 | 搜索请求同时携带原分类和关键词 | 输入或清空关键词时自动切换“全部”，在全部在售商品中搜索；搜索后保留“全部”选中状态 |

切换具体分类时清空原关键词；首页搜索入口同样进入“全部”。每页 10 件、追加加载、旧请求丢弃和详情返回保留状态继续生效。“全部”只显示在售且未删除商品。

实现文件：`wechat-miniprogram/pages/shop/index.js`。

回归验证：补充小程序页面与真实商品筛选服务组合测试，覆盖“速食方便”中搜索“薯片”得到其他分类商品、搜索后选中全部、点击全部清空关键词、空结果保留全部、首页搜索入口和详情返回保持搜索状态。

交付前验证：49 项相关检查、小程序 23 页面编译、663 项单元及审计检查、JSON / SQLite / PostgreSQL 冒烟检查通过；更新浏览器测试的提现金额及财务标签操作后，5 项端到端测试全部通过。
