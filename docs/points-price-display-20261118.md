# 积分价展示文字

后台商品新增及编辑增加“积分价（展示文字）”，支持最多 120 个字符的中文、英文和特殊符号，例如 `100积分/500g`、`Points × 100`。首尾空白会去除，留空则显示原有数值积分价。原积分价数字输入改名为“实际扣减积分（每件）”。

接口新增 `pointsPriceText` 字符串，原 `pointsPrice` 继续保持非负整数，参与积分扣减、现金补差和退款相关金额计算。展示文字不解析为金额；支持积分的商品上架仍要求实际积分大于零。权限、下架后编辑、库存校验保持原规则。

后台商品列表、纯积分列表、预览、小程序商品价格及网页商城同步支持展示文字，HTML 特殊符号按文本显示。购物车及结算合计继续显示实际积分，避免展示单位影响数量计算。SQLite 商品扩展 JSON 保存新字段；JSON 和 PostgreSQL 的状态存储无需结构迁移。

小程序需上传发布新版本，旧版本继续使用原数值积分价。会员码后台功能保持不变。
