# 零售价展示文字

零售价是独立的展示信息，后台新增、编辑及预览支持最多 120 个字符的中文、英文和符号，例如 `11.7元/500g`、`原价 $2 / pack`。输入内容去除首尾空白后保存，商品列表及用户端按文字展示，不追加货币符号或单位；历史数字零售价继续带 `¥` 显示。现金商品上架要求零售价展示内容非空，纯积分商品不展示零售价。

小程序首页、分类、商品详情、购物车和结算页，以及网页商城和后台列表同步支持。HTML 特殊符号按普通文本转义展示。实际订单金额继续由数值型会员价 `cashPrice` 计算，`regularPrice` 不参与结算。原有数字接口数据保持兼容，SQLite 的商品扩展 JSON 和 PostgreSQL 状态 JSON 均可保存文本，无需迁移表结构。

首页分类核对：线上首页配置及首页接口均已返回水乳饮品、速食方便、薯片膨化、饼干糕点、日用百货五个入口，本次不调整分类规则及配置。

小程序模板使用共用 WXS 格式化函数，本地编译脚本已加入 WXS 文件输入。小程序展示变更需上传发布新版本；后台及网页商城通过服务器部署生效。旧版小程序对带文字的零售价仍按数字判断，可能不显示，因此需配套发布新版。

验证覆盖文本创建上架、编辑、SQLite 重载、实际结算价格、特殊字符转义和旧数值展示，并执行小程序编译及后端完整测试。
