# 商品文档导入

2026-11-19。后台“商品管理 → Excel 批量导入商品”。

后台商品管理另有“导出全部商品 XLS”：下载 `商品数据.xls`，导出全部未删除商品（包括下架草稿），不受搜索或状态筛选影响，按后台商品排序。仅包含模板同名同序的 17 列和商品行，不添加模板说明行或其他字段。缺失数据留空，已知的 0 保留。名称、分类、条码、库存、销售价（当前 regularPrice）及会员价（当前 cashPrice）使用当前商品值，采购字段使用已保存的导入资料，不套用原价格快照、不计算会员折扣。仅有合并规格时放在“规格”列，主单位留空；导入后的规格未改动时保留原规格/主单位的拆分。没有商品时仅导出表头。Excel 单表超过 65535 个商品时续写后续工作表；导入限制仍遵循下文，不承诺所有导出文件无需补充便可重新导入。

`GET /api/admin/products/export.xls` 需要 `product:read`，返回真实 BIFF8 XLS，`Cache-Control: no-store`。导出不会修改商品或调用银豹。

1. 下载模板，或使用项目根目录的《商品导入模板.xls》。保留首行表头，第二行说明可保留或删除。
2. 填写商品，选择文件，点击“上传并检查”。名称、分类、进货价、销售价必填。
3. 根据反馈修改错误后重新上传。页面显示原 Excel 行号、字段和说明，不会跳过坏行导入其他商品；可下载完整文本校验结果。页面显示前 200 项问题及前 50 行预览，校验覆盖全文件。
4. 核对所有提醒，填写原因，确认导入。成功后均为下架草稿，可编辑补图并按正常规则上架。

仅支持真实 Excel 97–2003 `.xls`，不接受改后缀的 CSV、HTML 或 `.xlsx`。新版 Excel 文件需另存为 `.xls`。单文件 2 MiB、单批 1000 商品、最多 64 列且只能有一个非空工作表。公式须粘贴为值；损坏、加密、Excel 错误值和不合法格式会报错。

| 模板字段 | 导入规则 |
| --- | --- |
| 名称、分类 | 必填，最多 120 / 40 字符；已删除分类拒绝 |
| 条码 | 文本保留前导零；数字按显示值读取并提醒，超过 15 位的数字拒绝；重复条码拒绝；空条码提醒 |
| 规格、主单位 | 分别保留，合并为商品规格/单位，合并后最多 40 字符 |
| 库存量 | 非负整数，空值按 0 并提醒；大于 0 需 stock:write |
| 进货价 | 必填，非负金额，最多两位小数，仅后台原始资料保存 |
| 销售价 | 必填，非负金额，最多两位小数，映射商品展示零售价 |
| 批发价 | 可选非负金额，仅保留原始资料，不参加商城结算 |
| 会员价 | 实际现金结算价；空值按 0 并提醒，不套用销售价，0 不能上架 |
| 会员折扣 | 可选“是/否”，填写会员价时必须为“否”；“是”仅保留标记，不自动折算售价 |
| 库存上限、库存下限 | 可选非负整数，下限不能大于上限；保留采购资料，不改变现有库存告警逻辑 |
| 品牌、供货商 | 可选文本，最多 80 / 120 字符 |
| 生产日期 | Excel 日期或合法 YYYY-MM-DD / YYYY/M/D，统一保存为 YYYY-MM-DD |
| 保质期 | 正整数加单位，如 30天、12个月、1年，或长期/永久；纯数字按天处理并提醒 |

所有金额、库存上限为 100000000。纯积分分类不能用此模板导入，因模板无积分价及销售类型。买商品送会员分类沿用每件默认赠送 30 天规则，并在预览提醒核对。

接口均需后台认证及 product:write：

- `GET /api/admin/product-import/template`：下载 `.xls`。
- `POST /api/admin/product-import/preview?filename=商品.xls`：原始二进制请求体，`Content-Type: application/octet-stream`；200 返回校验报告，`valid=false` 不代表已导入。有效预览返回 `previewId`，有效期 30 分钟，绑定创建人。
- `POST /api/admin/product-import/commit`：JSON `{previewId, reason, acknowledgeWarnings}`；存在提醒时必须明确确认。再次检查原文件及现有商品、分类和权限。422 返回新的 `report`，本批无写入。

同一个预览重复提交不会创建第二批商品；成功回执写入 `config.productImports.batches`，重启后可复查。原始采购资料存入 `config.productImports.metadata[productId]`，仅后台商品列表附加 `importDetails`；用户商品接口和公共配置均不包含此资料。批次保存一次，库存流水、商品和操作日志一起持久化。失败不返回成功；预览仍在时可重试。重启丢失未提交预览时需重新上传。

不修改现有商品，不向银豹写入数据。文件不落地保存，内存最多保留 20 个待确认预览，过期淘汰。

验证：`node --test test/unit/product-import.test.js test/unit/product-publication.test.js test/unit/product-catalog-admin.test.js`；浏览器：`node --test --test-name-pattern="product document import" test/e2e/frontend-cdp.test.js`。

部署需安装锁定的 SheetJS 0.20.3 依赖（package-lock.json 中包含官方源及完整性校验）：在 dev/backend 执行 `npm ci --omit=dev`，更新后端与后台页面并重启服务。反向代理的请求体限制需至少 2 MiB。此功能代码完成不代表已部署服务器。
