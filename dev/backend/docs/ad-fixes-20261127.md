# 广告问题修改20261126 修复

按文档四项修改：

1. 会员页提示改为“买商品送会员专区中，‘买礼包送会员（单独购买）’商品核销后视为已用，无法退款。”页面使用文档中的中文双引号，红色、加粗、32rpx（正文30rpx）。本项为指定商品的提示文案修改。
2. 第二轮广告恢复：微信插屏 `show()` 可能返回 2001（启动时间限制）、2002（距上次插屏或激励视频间隔过短）、2003（已有广告播放中）；旧代码将它们和无广告填充统一显示“广告暂不可用”。修复后保留安全错误码，限制类错误等待60秒、临时无填充等等待30秒再由用户重试。等待时间是客户端退避，不保证微信届时必有广告。
   当前轮广告状态在播放前保留；“重试当前广告”恢复原 attempt 与 nextStep，不再新建一轮或重播已完成的视频。失败不计完成；仅真实完成回调后调用原服务端步骤确认接口。日奖励、服务器轮间20秒倒计时、顺序、令牌及幂等保持原规则。刷新/离开仍保留完整轮数，未完成组按原规则重新开始。
3. 会员页信息流下增加横幅，继续使用后台统一广告位。
4. 分类标题和箭头改为共享网格标题行；高度按文字自然增长，通常56rpx，减少上下空白，两侧同高对齐，适用于所有分类及折叠菜单。

验证覆盖：SDK频率/无填充报错、首轮/第二轮前置/后置插屏失败恢复、限频期间禁止重复请求、激励视频不重播、签到积分仅入账一次。广告平台实际是否填充及限频是否解除仍需真机验证。

`npm test` 通过832项单元/审计测试、JSON/SQLite/PostgreSQL冒烟测试及7项端到端测试。官方编译器通过22页、23个模板和样式。开发者工具确认会员提示、两处广告挂载正常；“卤辣素食”和“买商品送会员”标题两侧均为29px并水平对齐，未播放签到广告或领取正式奖励。
