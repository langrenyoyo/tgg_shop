## 开通通知

1. 微信公众平台 → 小程序 → 订阅消息，选用发货通知模板。2026-11-25 只读检查显示当前模板列表为空，需管理员先选用模板。
2. 商城后台 → 订单履约 → 纯积分订单发货通知：填写模板 ID、按微信模板填写字段及来源，勾选启用并保存。权限为 `integration:write`。
3. 支持订单号 `character_string`、商品名称/自提点 `thing`、时间 `time`、状态/配送方式 `phrase` 或 `thing`。数字后缀必须和所选模板一致；最多 5 个字段，未使用行留空。系统按类型限制长度，时间使用北京时间。
4. 上传新版小程序，用户下单时同意接收，或到订单详情点“接收发货通知”。旧订单没有历史授权，需用户补订阅后才能提醒。
5. 后台可查看未订阅、待发货、已发送、失败及结果待核查等状态；真实送达还需配置实际模板并取得用户授权后，用真机验证。

## 可靠性与边界

仅纯积分且现金金额为零的已付款订单可订阅；收件人取自登录账号，模板及收件人保存在服务端内部配置，不公开 OpenID、AppSecret 或 access_token。注册按订单幂等，模板字段和微信身份在授权时快照。退款/取消订单停止提醒，退款中暂停发送。

发送前持久化发送意图，成功后记录状态；超时、响应不明确或进程中断均不自动重发，避免消耗另一次授权或重复提醒。明确拒绝记录安全错误码。发送失败/结果不明时用户仍可在订单详情查看进度。发货通知不修改积分、支付、退款或库存记录。
