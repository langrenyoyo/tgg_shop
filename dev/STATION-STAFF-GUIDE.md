# 站点工作人员配置与验收

## 后台配置

1. 使用超级管理员或具有 `admin:manage` 权限的账号登录后台。
2. 在「代理与自提点」创建并启用自提点；此操作需要 `pickup_site:write` 权限。
3. 打开「站点工作人员」→「新增工作人员」，填写登录账号、姓名和独立密码。
4. 选择所属站点（可多选），勾选收货 / 拣货、提货核验、异常登记权限。不勾选操作权限时仅可查看。
5. 选择启用状态，填写操作原因，保存。账号唯一且不可改名，密码为 8 至 128 个字符。
6. 工作人员在小程序「我的 → 站点工作人员入口」使用账号密码绑定当前微信，以后点击「微信授权登录」进入。网页版站点端使用同一账号密码登录。

站点工作人员与后台管理员是独立账号体系。人员只能查看所属站点的订单；收货、提货、异常登记权限由后端逐项校验。

## 调岗、离职与换微信

- 编辑 / 授权：修改姓名、所属站点、操作权限及账号状态。
- 停用：阻止密码和微信登录，退出该账号已有会话；历史订单及操作记录保留。
- 重置密码：设置新的独立密码，清除登录错误锁定，退出已有会话。保留微信绑定，如交接给其他人还需解绑微信。
- 解绑微信：清除绑定，退出已有会话；必须使用账号密码重新绑定。

以上变更均记录操作原因和审计日志，释放该人员尚未完成的拣货占用，方便其他人员接手。已收货商品的提货位及收货记录不会因账号变更而移除。失效会话下次请求会返回登录页。

## 上线与旧账号兼容

- 本机联调：微信开发者工具默认连接 `http://127.0.0.1:5177`，请在同一地址的 `/admin` 后台维护工作人员。开发者工具中需启用「不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书」。仅开发者工具使用此默认值，开发版真机、体验版和正式版继续使用 HTTPS 环境。
- 如曾在开发者工具缓存中设置 `tgg_config.tggApiUrl`，该显式地址仍优先。需要恢复默认时，仅移除该字段后重新编译：`const cfg = wx.getStorageSync('tgg_config') || {}; delete cfg.tggApiUrl; wx.setStorageSync('tgg_config', cfg);`。
- 本地后台和线上后台的数据独立。在本地重置的密码不会同步到线上。真机测试须将后端和后台更新部署到同一个 HTTPS 环境，再在对应后台设置密码。

- 部署后重启后端，更新后台静态资源，并重新编译、发布小程序。
- SQLite 启动时自动补齐人员扩展数据列；JSON 和 PostgreSQL 状态存储保留人员密码哈希、权限及绑定信息。
- 旧站点账号保留既有操作权限。未配置独立密码的旧账号会在后台提示；应在后台重置独立密码。旧账号首次成功使用原配置密码登录时，会自动保存独立密码哈希，此后不再读取统一密码配置。
- 微信绑定需要后端已配置正确的 `WECHAT_APPID`、`WECHAT_APPSECRET`，小程序已配置可访问的 HTTPS 服务域名。
- 不向前端或审计日志返回密码哈希和微信 OpenID，仅显示是否已设置密码、是否已绑定微信。

## 验收流程

1. 创建只授权收货的人员 A 和只授权提货的人员 B，确认各自仅显示获授权操作。
2. A 领取并核对所属站点订单、收货上架；B 使用正确提货码完成提货。订单完成，重复核验不重复交付。
3. 尝试通过接口绕过按钮执行未授权操作，应返回 403；访问非所属站点订单应失败。
4. A 拣货时从后台撤销权限或停用，旧访问及刷新令牌均失效，其他授权人员能接手任务。
5. 重置密码后旧密码失效；解绑微信后该微信不能直接登录，重新绑定后恢复。
6. 保存后重启服务，确认账号、站点、密码及空权限（只读）均保留。
7. 小程序真机检查微信首次绑定、后续登录、停用退出及扫码操作。

自动验证：`npm run test:unit`；后台新增、授权、重置密码和停用的浏览器验证：`node --no-warnings --test --test-name-pattern="station worker configuration" test/e2e/frontend-cdp.test.js`（在 `dev/backend` 目录执行，需要 Chrome 或 Edge）。微信服务在自动测试中使用模拟响应，真实绑定需真机验收。
