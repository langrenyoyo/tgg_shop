# TGG Shop 微信小程序端

## 说明

这是按当前项目接口生成的微信小程序端骨架，已接入：

- 登录
- 首页
- 任务列表 / 任务详情 / 任务提交
- 签到
- 邀请
- 我的 / 订单 / 积分

## 接口

默认指向本地后端：

```text
http://127.0.0.1:5190
```

可在小程序端通过存储 `tgg_config` 覆盖：

```js
wx.setStorageSync("tgg_config", {
  tggApiUrl: "http://127.0.0.1:5190"
});
```
